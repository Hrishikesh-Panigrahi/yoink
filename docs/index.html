Install

Download, run, done.

Everything it needs is inside the installer. Nothing else to set up.

Download

One 64-bit installer, Yoink-Setup.exe.

Run it

Installs just for you, so Windows won't ask for an administrator password. Tick the boxes for a desktop shortcut, magnet: links, and .torrent files.

Start yoinking

Choose where downloads go on first launch. Prefer nothing installed? The portable .exe runs from anywhere.

Windows will probably warn you

Yoink isn't code-signed yet, because certificates cost money. SmartScreen may say "Windows protected your PC". Click More info, then Run anyway.

If you'd rather check the file first, every release ships a SHA256SUMS.txt. Compare it against Get-FileHash .\Yoink-Setup.exe -Algorithm SHA256.

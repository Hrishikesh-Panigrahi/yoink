Features

Four things it does well

No feature gates, no premium tier, no sign-up — all of it ships in the installer.

One search box, sixteen sites

Results come back merged into a single list — scored on swarm health, then deduplicated by infohash so the same release never appears twice.

Take only the files you want

Set priorities per file and skip the extras. Quit mid-download and it picks up exactly where it stopped.

Have Pending

Adds torrents while you're away

Point it at a watch folder, subscribe to an RSS feed with a title regex and seeder floor, or just copy a magnet link and let the clipboard watcher catch it.

Behaves like a real Windows app

Seeds quietly from the tray, tells you when something lands, opens magnet: links straight out of your browser, and answers to a command palette.

Appearance

Eight themes. Try them on this page.

Each preset retunes accents, surfaces, and contrast — not just a hue shift. Click one and the whole site changes with it.

Install

Download, run, done.

Everything it needs is inside the installer. There is nothing else to set up and nothing to configure first.

Download

One 64-bit installer, Yoink-Setup.exe, straight from the button above.

Run it

Installs just for you, so Windows won't ask for an administrator password. Tick the boxes for a desktop shortcut, magnet: link handling, and .torrent files.

Start yoinking

Choose where downloads should go on first launch, and that's it. Prefer nothing installed at all? The portable .exe runs from anywhere, including a USB stick.

Windows will probably warn you

Yoink isn't code-signed yet — certificates cost real money — so SmartScreen may say "Windows protected your PC". Choose More info → Run anyway to continue.

To verify first, every release ships a SHA256SUMS.txt. Compare it against Get-FileHash .\Yoink-Setup.exe -Algorithm SHA256 in PowerShell.

For developers

Or run it from source

A PyQt6 shell hosting a web-tech UI over QWebChannel, with libtorrent doing the swarm work.

Classes are reserved for what the frameworks require — everything else is a module-level function with enums and frozen dataclass DTOs. Builds come from build.py (PyInstaller + Inno Setup) and ship via a tag-driven GitHub Actions workflow. 

# clone and set up
git clone https://github.com/Hrishikesh-Panigrahi/yoink
cd yoink
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt

# run it
$env:PYTHONPATH = "$PWD;$PWD\src"
python src\main.py

# package Yoink.exe + installer
python build.py

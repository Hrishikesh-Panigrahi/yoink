What it does

The whole feature list, in one screen

No tiers, no accounts, nothing held back for a paid version. All of it ships in the installer.

Health ranking

Scored on seeders, quality and source, then deduplicated by infohash.

Safety flags

Catches an .exe hiding in a film, files far too small, locked archives.

Filters

Region, category, quality, and sort by match, seeds, size or age.

Source health checks

Graded pings so you can see what's reachable and switch off what isn't.

TMDB metadata

Posters, ratings, runtime, plot and a trailer link. Add a free key.

Per-file priorities

Take the film, skip the four subtitle tracks you'll never open.

Resume anywhere

Fast-resume data per torrent, so closing the app costs you nothing.

Labels

For when one downloads folder stopped being enough.

Watch folder

Drop a .torrent in and it starts without you.

RSS subscriptions

Title regex plus a minimum-seeder floor. Seen items aren't re-added.

Clipboard watcher

Copy a magnet link anywhere and Yoink offers to take it.

Quiet hours

Lower caps on a schedule, full speed again afterwards.

Speed and queue caps

Up, down, how many run at once, and a seed ratio to stop at.

Magnet handler

Opens magnet: links and .torrent files from the browser.

Proxy

http, https or socks5, with a custom user agent.

Local only

A SQLite file on your machine. No account, no sync, no telemetry.

Install

Download, run, done.

Everything it needs is inside the installer. Nothing else to set up.

Download

One 64-bit installer, Yoink-Setup.exe.

Run it

Installs just for you, so Windows won't ask for an administrator password. Tick the boxes for a desktop shortcut, magnet: links, and .torrent files.

Start yoinking

Choose where downloads go on first launch. Prefer nothing installed? The portable .exe runs from anywhere.

Windows will probably warn you

Yoink isn't code-signed yet, because certificates cost money. SmartScreen may say "Windows protected your PC". Click More info, then Run anyway.

If you'd rather check the file first, every release ships a SHA256SUMS.txt. Compare it against Get-FileHash .\Yoink-Setup.exe -Algorithm SHA256.
